# 西方占星 Skill

摘自 [taibu](https://github.com/hhszzzz/taibu) 的 `astrology` 工具说明与解读框架。

## 何时使用

- 本命性格 / 核心特质
- 事业、爱情、财富等主题（以太阳·元素比例·上升粗估为据）
- 近期走向、日运感、警惕与提示

## 参数文档

见 [references/astrology.md](references/astrology.md)

完整盘（月亮/精确上升/相位）需出生钟点与经纬度；Vouch 当前本地引擎提供：太阳星座、元素/模式比例，有出生时间时粗估上升。缺信息时只用已有数据，不要在正文里追问「请补时辰」。

## 解读指引

见 [interpretation/astrology.md](interpretation/astrology.md)

要点：

1. **本命三要素**：太阳（核心自我）、月亮（情感需求）、上升（外显）——有则用，无则只谈太阳 + 元素/模式比例。
2. **盘面重心**：元素与模式分布，找出最突出主题。
3. **流运/近期**：把比例当作「近期天气」，谈可能课题与应对，发展性语言，不宿命恐吓。
4. 输出可含：核心特质摘要 → 分层展开 → 警惕与提示；语气像陪伴者，短段落、说人话。
